# Maria Khoroshilova — static portfolio
Plain HTML, CSS and vanilla JavaScript. No build step, no dependencies.
Open `index.html` in a browser, or upload the whole folder to any static host
(Netlify, GitHub Pages, Cloudflare Pages, S3, shared hosting).
- `assets/styles.css` — all styles  ·  `assets/site.js` — menus + image pop-up  ·  `assets/img/` — images
